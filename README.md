# CRUD Operations in C (Data Structures + File Handling)

This repository contains C programs that demonstrate **CRUD operations** (Create, Read, Update, Delete) in two contexts:

1. **File Handling in C**  
   - Create a file and write data  
   - Read file contents  
   - Update/append data  
   - Delete a file  
   - Replace specific lines in a file  

2. **Data Structures (DSA) Implementations**  
   - **Stack using Array**  
   - **Stack using Linked List**  
   - **Queue using Array**  
   - **Queue using Linked List**

---

## 📂 Project Structure

- `crud.c` → File handling CRUD operations  
- `queue_using_array.c` → Queue implementation with arrays  
- `queue_using_linkedList.c` → Queue implementation with linked lists  
- `stack_using_array.c` → Stack implementation with arrays  
- `stack_using_linkedlist.c` → Stack implementation with linked lists  
- `example.txt`, `newfile.txt` → Sample files for file handling  
- `a.exe` → Compiled executable (ignored in `.gitignore` ideally)
